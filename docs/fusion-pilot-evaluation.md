# 融合版评测 / Fusion Evaluation

本页说明正式融合权重 **DeepSignal-S1-1.0** 的公开结果口径。原始配对成绩保留于 [`results/fusion-2026-10-30.json`](../results/fusion-2026-10-30.json)，新增等待与排队统计位于 [`results/fusion-2026-10-30-traffic.json`](../results/fusion-2026-10-30-traffic.json)。表格不得从README中的数值反向抄录。

## 当前结果

正常视觉采用三方比较：融合S1、冻结工程固定配时、YOLO+MP。南沙正常主表覆盖九路口、八类预定车流，共72案例；Town覆盖五类车流、种子18040，共5案例。当前主页统一展示平均每车等待时间、平均排队车辆数和平均每车行程时间，具体口径见[交通指标说明](traffic-metrics.md)。

特殊视觉只比较S1与YOLO+MP：失焦σ=9、水平31像素运动模糊、整回合固定偏航±15°/俯仰±8°、动态抖动偏航/俯仰峰值5°及横滚峰值2.5°。南沙每条件9案例，Town每条件5案例。完整逐条件结果、案例来源、失败字段和时域见公开JSON。

南沙使用1298秒评估时域，Town使用518秒评估时域。当前两场景都将车辆行程耗时总量除以正式车辆数，得到秒/车；未完成车辆计入截止时已耗时，不称为所有车辆完整行程平均值。等待同样按车辆加权，排队采用共同发车窗口的时间均值。不同场景不合并绝对值。

历史发布表把南沙逐案例均值求和（7540.24、9193.32、7648.36），Town则把行程总量求和（10623.80、16040.30、10625.20）。这些原始成绩未变，但不是当前每车表格的单位。南沙改为按车辆加权后，汇总改善率与原来等权案例汇总略有不同；这是汇总定义变更，不是重跑或换权重。不得混用两种百分比。

2026-10-30用户另行批准补录南沙正常视觉YOLO+MP的72个同计划案例，解决旧回合未保存灯态导致等待、排队缺失的问题。补测整行三项均来自新批次；原缺日志成绩归档不改，S1与冻结固定不重跑。只有72案例齐备后才切换主页，不能把旧MP行程与新等待、排队拼接。原271个可重放记录和新增72个视觉回合的来源在交通统计JSON中分别标明。

## 协议

- 唯一固定基线是冻结工程固定配时：南沙各路口工程表，Town为31/6/31/6秒。
- 三帧按2秒间隔覆盖4秒观察窗。模型为未量化BF16的DeepSignal-S1融合权重。
- Town两臂保留5秒绿灯尾段，再执行3秒黄灯和2秒全红。
- YOLO车道画线在正常机位完成并冻结。固定角度条件先画线、后改变相机，整回合固定且不重新标定。
- 闭环策略会改变后续交通状态，因此配对双方不要求看到逐像素相同的后续画面。

## 范围限制

南沙特殊视觉仅为九路口各一个高流量均衡案例、种子97001；Town仅为五类车流、单种子18040。这是开发小批，不是多车流、多种子全量验收。动态抖动下两个场景相对YOLO+MP改善均约6.7%，未达到预先设定的10%开发目标，结果保留。

南沙旧执行器存在已知红龄记账限制：某相位首次决策即切换时，后续红龄可能多算该段最小绿灯。双方沿用相同协议，但这不等于该协议已经通过完整正确性验收。Town本轮使用修正后的绿灯尾段与红龄起点。

## 录制与批次轨迹边界

新录制的南沙J08、失焦σ=9案例得到S1=133.73、YOLO+MP=133.27，S1略差0.35%；原评测批次同案例为S1=110.46、YOLO+MP=133.27。新录制闭环在仿真25.1秒已出现首次动作分歧，早于120秒录像起点，说明录制回合并不是原批次轨迹的确定性重放。该单次录像保留，不更换为获胜案例；录制分数不写回原始批次表，其余预选素材也不因胜负重录。

为排除发布权重与推理路径差异，已选取5个完全相同的图像与state请求比较research和public路径：动作全部一致，所有动作概率的最大差为0。正式HTTP服务按A-C-A顺序重复请求也保持稳定。因此目前没有发现权重打包或推理路径不同；独立闭环中的观测或渲染初始化差异仍未精确定位。现有证据不足以把差异归因于某个具体TAA机制，也不能保证单次录制重现批次中的相同优势。

GIF与MP4用于展示真实输入条件、控制行为和画面内单例指标，不代表每个展示案例都由S1获胜。整体效果只依据预定案例集合的配对汇总。

RTX 5090上的6823次三帧模型请求平均485.4毫秒，中位数479.0毫秒；首请求与后续请求分开统计，尾部可超过1秒。延迟不含相机、渲染和控制执行。未验证量化边缘部署，也不承诺全部请求小于1秒。

This release uses one fused checkpoint in both scenes. Clean views use the three-controller comparison; perturbed views use S1 versus YOLO+MP only. The pilot is finite-horizon, scene-specific and deliberately not presented as a statistical or universal SOTA claim.
