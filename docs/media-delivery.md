# 融合版素材交付

本轮交付供后续90秒视频剪辑使用：**不制作最终成片，不添加中文旁白、音乐或配音。** 模型仍为同一份融合权重DeepSignal-S1-1.0，未重新训练。

## 公开媒体

公开仓库：[DeepSignal-S1-Media](https://huggingface.co/datasets/AIMS2025/DeepSignal-S1-Media)。模型和场景资产的下载审批设置不变。GitHub使用原生视频附件，避免外部视频源被网页策略阻止；HF保留高质量MP4。网页附件对应表见`results/fusion-2026-10-30-github-videos.json`。

当前目录为`media/fusion-1.0/v3/{en,zh}/`，中文README使用中文界面，英文README使用英文界面。南沙与Town各提供：

- 正常视觉：`{scene}-clean.mp4`，工程固定配时、S1、YOLO+MP三方比较。
- 特殊视觉：`{scene}-{df9,mb31,angle15,shake5}.{mp4,gif}`，S1与YOLO+MP比较。
- 每项的JSON元数据与`index.json`：记录案例、条件、控制动作来源和成绩。

主页不显示静态图，不折叠GIF画廊。历史图表仅作为下载归档，不再嵌入当前首页。

## 画面与播放

画面只保留**实际模型输入与右侧实时指标**；不叠加清晰旁观总览。S1和YOLO+MP的最新实际决策、决策时刻及当前灯态由录像日志读取，S1同时显示真实模型推理耗时，不编造解释或置信度。YOLO画线是冻结的真实检测区域，展示叠加不参与决策。

视频将控制器上下排列，各占整行：正常比较960×1920，特殊比较960×1280，不再把两到三个控制器横向压进一条窄画面。每段保留901个原始连续帧；对应仿真120—300秒，MP4以25帧/秒、仿真时间5倍速播放，时长36.04秒。采用H.264 Constrained Baseline、level 4.1、YUV420及faststart，并增加HF独立文件播放器作为备用。该编码与备用入口用于改善兼容性，不等于已经定位用户浏览器播放失败的具体根因。原始母片保留，没有使用AI补帧或合成车辆运动。

所有GIF均为960×320、12帧/秒，网页按整列宽度展示。抖动GIF不再缩成600像素，而是保留宽度、改为同一24秒仿真窗口（5倍速约4.8秒，取原定60秒高密度窗口中间24秒）；其他条件仍为60秒、约12秒。文件均低于4.8MB。原先Town大GIF被GitHub代理以`Content length exceeded`拒绝，这次同时解决文件限制与预览过小问题。完整视频仍保留180秒仿真内容。

GIF窗口按双方合计在网车辆数最高选择，并列取最早窗口，**不按S1优势挑时段**。

## 只展示十字交叉口

展示案例均为四进口十字交叉口。原南沙J04是三进口路口，已移出展示；运动模糊改为J05，动态抖动改为J07。替换案例从四进口候选中，按原评测单例改善幅度最接近原批次整体改善选定，再进行独立录像；不依据新录像胜负选赢家。完整选择记录见`results/fusion-2026-10-30-media-fourway-cases.json`。

原有批次结果不改，评测仍覆盖原来的路口，包括J04。其余合格录像沿用原始文件，仅补录两个替换案例的S1/MP四个回合。所有录像使用相同融合权重及原条件。

录像并非原批次轨迹重放。例如南沙J08失焦录像S1为133.73秒/车、MP为133.27秒/车，S1略差，仍如实保留。不能将预定配对表的整体优势冒充每段GIF单例的优势。新J05运动模糊录像为116.12对216.11秒/车；新J07抖动录像为135.20对150.18秒/车。

## 指标与剪辑交付

当前表格使用平均每车等待、平均排队车辆、平均每车行程，详细定义见[交通指标](traffic-metrics.md)。逐案例原始数据来自`results/fusion-2026-10-30.json`，补充交通统计来自`results/fusion-2026-10-30-traffic.json`及同名CSV。

素材中的动态平均等待按已入网车辆累计停车等待计算，包含共同预热车辆；正式表格按评测车辆计算并包含拥堵入网等待，两者不能混用。录像最终平均行程只属于该次录像。所有画面上的动作、指标均可追溯到分臂原始录像和逐帧灯态重放。

南沙正常视觉原72个YOLO+MP回合未保存动作/灯态历史。用户已于2026-10-30批准只补跑这72个对照回合；补跑整行采用同批等待、排队及行程，原历史成绩保留，不从原总行程分数推测缺失项。

仿真资产继续使用`DeepSignal-S1-Scenes-v3.tar.gz`并配合最新GitHub代码；本轮不重复上传27.60GiB运行资产，不改变下载权限。
