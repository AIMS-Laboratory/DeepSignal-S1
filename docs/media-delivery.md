# 融合版素材交付

本轮交付供后续90秒视频剪辑使用：**不制作最终成片，不添加中文旁白、音乐或配音。** 模型仍为同一份融合权重DeepSignal-S1-1.0，未重新训练。

## 公开媒体

当前公开观看入口为GitHub首页、仓库内 `assets/previews/` 和已发布的GitHub原生视频附件。2026-10-30匿名检查发现HF媒体源返回 `401 GatedRepo`，因此首页不再依赖该源加载动图。本次未改变模型、场景或HF媒体库的访问权限。视频附件对应表见 `results/fusion-2026-10-30-github-videos.json`。

HF历史源目录为`media/fusion-1.0/v4/{en,zh}/`，中文README使用中文界面，英文README使用英文界面。南沙与Town各提供：

- 正常视觉：`{scene}-clean.mp4`，工程固定配时、S1、YOLO+MP三方比较。
- 特殊视觉：`{scene}-{df9,mb31,angle15,shake5}.{mp4,gif}`，S1与YOLO+MP比较。
- 每项的JSON元数据与`index.json`：记录案例、条件、控制动作来源和成绩。

当前首页优先显示两组代表动图；其余六组按干扰类型展开，每组都提供视频直达和静态封面。当前结果汇总图常显，完整数值与三指标图可展开。

## 画面与播放

画面只保留**实际模型输入与右侧实时指标**；不叠加清晰旁观总览。S1和YOLO+MP的最新实际决策、决策时刻及当前灯态由录像日志读取，S1同时显示真实模型推理耗时，不编造解释或置信度。YOLO画线是冻结的真实检测区域，展示叠加不参与决策。

GitHub会将原生视频包装为自己的播放器，忽略传入宽度，并限制最高640像素；纯竖片仍会缩成窄列。因此当前正常与特殊视频统一采用1280×960的4:3布局，各控制器占一行，实际输入与指标/决策并列。网页预览取原定高密度60秒仿真窗口，保留300个连续原始帧，以25帧/秒、5倍速播放为12秒；未按S1优势选窗口。采用H.264 Constrained Baseline、level 4.1、YUV420及faststart，另附HF独立文件播放器备用。原始901帧、180秒仿真内容的36.04秒比较母片仍在旧目录`media/fusion-1.0/{en,zh}/`保留。没有AI补帧或合成运动。

已确认的显示问题是播放器改写尺寸与初始化小框，不能把它等同于用户浏览器播放失败的唯一根因。匿名直连附件可返回视频字节；发布检查必须等待真实预览加载，然后点击原生播放按钮，不能仅调用脚本`play()`便宣称用户操作已验证。

首页两组代表动图沿用Town固定偏角和南沙运动模糊，另外六组按四种干扰类型展开。正常视觉保留两个可展开的原生视频。20段中英文视频均保留GitHub附件映射，不删除原素材。

当前16份GIF由已发布GitHub视频转码，不改变原有5倍速、布局、模型动作或指标。非抖动预览保留完整12秒视频窗口，宽800像素、8帧/秒；抖动预览取视频中间4.8秒（仿真24秒），宽640像素、6帧/秒，完整12秒视频仍可直接观看。每个GIF低于4.8MB，首次画面另存为JPEG备用。转码不补帧、不合成内容、不按胜负另挑窗口。来源、文件校验值、尺寸与时长见 `assets/previews/manifest.json`。

历史HF v4 GIF采用960×320横向布局；本次使用GitHub已发布的4:3视频作源，不依赖审批媒体源。早期曾发生GitHub代理的文件大小限制；当前匿名401权限问题与历史大小限制分别记录，不混作一个原因。

原视频窗口按双方合计在网车辆数最高选择，并列取最早窗口，**不按S1优势挑时段**。

## 只展示十字交叉口

展示案例均为四进口十字交叉口。原南沙J04是三进口路口，已移出展示；运动模糊改为J05，动态抖动改为J07。替换案例从四进口候选中，按原评测单例改善幅度最接近原批次整体改善选定，再进行独立录像；不依据新录像胜负选赢家。完整选择记录见`results/fusion-2026-10-30-media-fourway-cases.json`。

原有批次结果不改，评测仍覆盖原来的路口，包括J04。其余合格录像沿用原始文件，仅补录两个替换案例的S1/MP四个回合。所有录像使用相同融合权重及原条件。

录像并非原批次轨迹重放。例如南沙J08失焦录像S1为133.73秒/车、MP为133.27秒/车，S1略差，仍如实保留。不能将预定配对表的整体优势冒充每段GIF单例的优势。新J05运动模糊录像为116.12对216.11秒/车；新J07抖动录像为135.20对150.18秒/车。

## 指标与剪辑交付

当前表格使用平均每车等待、平均排队车辆、平均每车行程，详细定义见[交通指标](traffic-metrics.md)。逐案例原始数据来自`results/fusion-2026-10-30.json`，补充交通统计来自`results/fusion-2026-10-30-traffic.json`及同名CSV。

素材中的动态平均等待按已入网车辆累计停车等待计算，包含共同预热车辆；正式表格按评测车辆计算并包含拥堵入网等待，两者不能混用。录像最终平均行程只属于该次录像。所有画面上的动作、指标均可追溯到分臂原始录像和逐帧灯态重放。

南沙正常视觉原72个YOLO+MP回合未保存动作/灯态历史。用户已于2026-10-30批准只补跑这72个对照回合；补跑整行采用同批等待、排队及行程，原历史成绩保留，不从原总行程分数推测缺失项。

仿真资产继续使用`DeepSignal-S1-Scenes-v3.tar.gz`并配合最新GitHub代码；本轮不重复上传27.60GiB运行资产，不改变下载权限。

## 重新生成GitHub预览

在独立工具环境安装 `Pillow` 和 `imageio-ffmpeg` 后运行 `python scripts/build_homepage_previews.py`。源视频缓存在忽略目录 `.local/media-preview-sources/`；输出到 `assets/previews/`，并生成来源与校验清单。此过程只转码已发布录像，不运行模型或交通实验。
