# YOLO+MP Detector

The combined scene archive includes the stock `yolo11m.pt` detector used by the paired tests, together with the upstream Ultralytics license. It is a baseline artifact, not part of DeepSignal-S1.

统一场景包内附测试使用的原版 `yolo11m.pt` 检测器及上游 Ultralytics 许可。该文件仅用于 YOLO+MP 对照，不属于 DeepSignal-S1。

Use Ultralytics **8.4.175** with the inference environment's matching PyTorch/torchvision installation. The model is distributed separately from Git-tracked source files.
